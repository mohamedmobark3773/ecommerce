# SouqX E-Commerce Platform

A full-stack e-commerce project built with the MERN-style stack: a Node.js/Express/MongoDB backend and a Next.js (TypeScript) frontend.

## Tech stack
- **Frontend:** Next.js, React, TypeScript, Tailwind CSS, Redux Toolkit, TanStack Query, Radix UI, Recharts
- **Backend:** Node.js, Express, MongoDB (Mongoose), Redis, BullMQ, Socket.IO, JWT auth, Joi/Zod validation
- **Tooling:** ESLint, Prettier, Jest

## What is inside
- **Back-end** is organized by feature modules: auth, users, products, categories, brands, cart, wishlist, orders, payments, shipping, coupons, reviews, search, seller, admin, analytics, chat, notifications, and uploads.
- **front-end** has feature folders for home, shop, product, cart, checkout, orders, wishlist, auth, and seller and admin dashboards.

## Run locally
```bash
# Backend
cd Back-end
npm install
npm run dev

# Frontend (copy .env.example to .env.local and set the API URL first)
cd front-end
npm install
npm run dev
```
